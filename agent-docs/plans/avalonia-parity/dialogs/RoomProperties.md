# Room Properties dialog (T1.4a)

Reference: `legacy/src/Trizbort/UI/RoomPropertiesDialog.cs` (RPD.cs), `RoomPropertiesDialog.Designer.cs` (RPD.D.cs), `ObjectListEditor.cs` (OLE.cs).
Avalonia: `src/Trizbort.Avalonia/Views/Dialogs/RoomPropertiesDialog.axaml` (axaml), `src/Trizbort.Avalonia/ViewModels/RoomPropertiesViewModel.cs` (VM), `src/Trizbort.Avalonia/Services/DialogService.cs:224-239`.
Screenshots: `screenshots/winforms/RoomPropertiesDialog__*.png`, `screenshots/avalonia/RoomProperties__*.png`.

Overall layout difference: the legacy dialog keeps Name, Subtitle, Border Style, Start/End/Dark and Reference **above** a five-tab strip (Description, Objects, Colors, Regions, Room Shapes), so they are visible on every tab. Avalonia has four tabs (General, Description & Objects, Shapes & Corners, Custom Colours) and moves those controls into General or Shapes.

## 3. Recommendation for Lee

Keep the Avalonia tab structure (it is tidier and the merged Description & Objects tab is a good idea) but restore the context it dropped. Specifically: (1) put Name, Subtitle, Reference, Start/End/Dark in a header above the tab control so they remain visible on every tab as in the reference; (2) restore Custom Position + Down/Right (data is already in the model, so this is a VM/axaml add) next to the Objects Position control, and consider keeping the arrow-grid for Position; (3) add the missing option values (Border Style "None", the four corner Second-Fill locations) and put Second Fill Location on the same row as Second Fill; (4) show friendly item text instead of raw enum names via a converter; (5) make the Corner Radii group visible only when Shape = RoundedCorners; (6) port name validation and the start-room confirmation into the VM/`DialogService` so OK cannot apply an empty name; (7) wire `ObjectListEditor` (Tab/Enter indent) into the Objects TextBox and restore the Object Syntax help as an expander or tooltip; (8) add Alt access keys, let the text areas stretch, and remember last-used tab. The shape preview and region swatches are lower priority "nice to have" but cheap with the existing drawing code. Do not revert to the legacy single always-visible header plus five tabs wholesale.
