# Trizbort: Recast user guide

Trizbort: Recast is a map editor for interactive fiction. Draw rooms and the ways between them as you play, or let
**Automap** draw the map for you from the game's transcript. Recast runs on Windows, Linux and macOS.

![Recast automapping The Lighthouse: the map, the automap panel beside it, and a label listing the treasures.](images/main-window.png)

*Automapping a small game. The token shows where you are, and the panel on the right follows the game.*

## Older versions

Recast opens and saves the same `.trizbort` maps as the original Trizbort and Trizbort 2. Everything useful from the
original guide is in this one, as it works in Recast. See [Trizbort's story](more-help.md#trizborts-story) for where it came
from.
