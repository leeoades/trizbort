# Neat layouts

Lee's hand-tidied maps, the target for Tidy Map and automap's tidy as you go (see the "What a neat map looks
like" notes in the project).

- `hollywood-hijinx-nov-13-neat.trizbort`: the first part of Hollywood Hijinx: the grounds, the ground floor of the
  house as its own area, and the cellar and the chimney as separate floors.
- `A`–`E`: small puzzles, each with a `-rough` version (as automap might leave it) and a `-neat` version (as Lee
  tidied it). C was already neat as it was.
  - A, same spot: two rooms want the same place; the row is stretched so both fit.
  - B, busy hub: all four compass sides plus up, down and in.
  - C, long corridor: kept straight.
  - D, twisty forest: one-way exits that don't lead back, laid out as a triangle.
  - E, diagonals: straight and diagonal exits on one grid.
