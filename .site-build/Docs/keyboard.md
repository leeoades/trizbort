# Keyboard shortcuts

[Back to the guide](index.md)

On a Mac, use **Cmd** wherever this page says **Ctrl**. Every shortcut is also shown beside its command in the menus.

## Files

| Keys | Does |
|---|---|
| Ctrl+N | New map |
| Ctrl+O | Open a map |
| Ctrl+Shift+O | Open a map from the web |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as |
| Ctrl+Alt+S | Smart Save: save, plus a PDF and an image |
| Ctrl+B | Save a backup copy |

Exports have shortcuts of their own: see [Exporting](exporting.md).

## Adding and editing

| Keys | Does |
|---|---|
| R | Add a room |
| L | Add a label |
| B | Add a background, behind the selected rooms |
| J | Join the selected rooms |
| F2 | Rename |
| Alt+Enter | Properties |
| Delete or Backspace | Delete |
| Alt+Delete | Delete all the room's joins |
| Ctrl+C, Ctrl+X, Ctrl+V | Copy, cut, paste |
| Ctrl+D | Duplicate |
| Ctrl+Z | Undo |
| Ctrl+Y or Ctrl+Shift+Z | Redo |
| Esc | Cancel a drag, or select nothing |

## Rooms

| Keys | Does |
|---|---|
| K | Dark or lit |
| Ctrl+F5 / Shift+F5 | Start room / end room |
| Shift+F2 | Change region |
| Ctrl+H, Ctrl+E, Ctrl+R, Ctrl+8 | Straight, elliptical, rounded or octagonal |
| Ctrl+Alt+C | Copy the room's colour |
| ; | Adjust which ports the joins use |
| W / Ctrl+W / Shift+W / Alt+W | Swap two rooms' objects / names / looks / regions |
| Ctrl+Alt+arrow | Resize what's selected |

## Joins

| Keys | Does |
|---|---|
| P / T | Plain / dotted line |
| A | One-way arrow |
| V | Reverse it |
| U, D, I, O | Label it up, down, in or out |

## Selecting

| Keys | Does |
|---|---|
| Ctrl+A | Select everything |
| 0 | Select the start room |
| Ctrl+Shift+A | Select the rooms in some regions |
| Number pad | Select the room in that direction |
| Ctrl+arrow | Select the room that way, or add one and join it |
| Shift+arrow | Select the join that way |
| Arrows | Move what's selected, or pan the map |
| Ctrl+F | Quick Find |

## View

| Keys | Does |
|---|---|
| Ctrl+Plus / Ctrl+Minus | Zoom in / out |
| Ctrl+0 | Zoom to 100% |
| Ctrl+Home | Fit the whole map in the window |
| Home | Reset the view |

## Automap

| Keys | Does |
|---|---|
| F10 | Next move |
| F9 | Previous move |
| F5 | Play to the end |

## Help and settings

| Keys | Does |
|---|---|
| F1 | This guide |
| Ctrl+, | Application settings |
| Ctrl+Shift+, | Map settings |
